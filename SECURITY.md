# Security Policy

sixshark, sharkbait, poolshark, and sharkdns are offensive network tools.
They are provided for authorized security testing only — testing networks
you own or have explicit written permission to test. See [LICENSE](LICENSE)
for the full authorized-use disclaimer. Issues and pull requests describing
use against networks without that authorization will be closed.

## Reporting a vulnerability

If you find a bug in one of these tools that could cause unintended harm
beyond its documented purpose (e.g. a crash, memory-safety issue, or
behavior that affects hosts/networks outside the one being tested), please
open a GitHub issue describing it. There is no other private/security-only
reporting channel for this project at this time.
